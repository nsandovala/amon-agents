# bootstrap scripts

Scripts para aplicar plantillas base del ecosistema AMON a nuevos repos o módulos.

## Archivos

- `bootstrap.sh` → script para macOS / Linux
- `bootstrap.ps1` → script para Windows PowerShell

## Perfiles soportados

- `node-next`
- `python-radar`
- `mixed`

## Uso

### macOS / Linux

```bash
./bootstrap/scripts/bootstrap.sh <profile> <target_dir>
